| Word | Means | Read more |
|---|---|---|
| **A2A** | The protocol agents use to consult colleagues, in the same installation or in another | [Agent to agent]({{ '/morgana/operations/a2a/' | relative_url }}) |
| **Actor** | A worker that owns its state and talks by messages only | [Actors]({{ '/morgana/pillars/actors/' | relative_url }}) |
| **Agent** | A domain specialist: one intent and one block of prose and optionally tools | [Agents]({{ '/morgana/pillars/agents/' | relative_url }}) |
| **Alembic** | The authoring workbench that turns an interview into a domain | [Alembic]({{ '/alembic/' | relative_url }}) |
| **Archive** | The one download Alembic produces: project and prose and code | [Alembic]({{ '/alembic/' | relative_url }}) |
| **Cauldron** | The browser channel | [Cauldron]({{ '/channels/cauldron/' | relative_url }}) |
| **Channel** | Where a person meets Morgana: the transport and the client | [Channels]({{ '/channels/' | relative_url }}) |
| **Classifier** | The actor that ranks which intents a message could belong to | [Actors]({{ '/morgana/pillars/actors/' | relative_url }}) |
| **Collision** | Two intents ranked too close to call, so the user is asked | [In the box]({{ '/morgana/configuration/in-the-box/' | relative_url }}) |
| **Consultation** | An agent asking a colleague a question mid-turn | [Agents]({{ '/morgana/pillars/agents/' | relative_url }}) |
| **Context** | What an agent remembers. Private by default | [Context]({{ '/morgana/pillars/context/' | relative_url }}) |
| **Domain** | Your business as Morgana knows it: intents and agents | [Your domain]({{ '/morgana/configuration/domain/' | relative_url }}) |
| **Dust** | Morgana's currency of AI consumption, like casino chips: real tokens exchanged per tier by a small equation. 1 dust is US$ 0.015 | [Dust, models and pricing]({{ '/morgana/configuration/dust-and-models/' | relative_url }}) |
| **Fail closed** | When a check cannot decide it refuses | [Guard rails]({{ '/morgana/operations/guard-rails/' | relative_url }}) |
| **Grimoire** | The rich terminal channel. Also the image of Morgana's book of agents | [Grimoire]({{ '/channels/grimoire/' | relative_url }}) |
| **Guard** | A check on one door: user message or tool result or partner question | [Guard rails]({{ '/morgana/operations/guard-rails/' | relative_url }}) |
| **Handshake** | What a channel announces when a conversation starts | [Channels]({{ '/morgana/pillars/channels/' | relative_url }}) |
| **Harness** | The live suite that measures prompt behaviour | [PromptHarness]({{ '/prompt-harness/' | relative_url }}) |
| **Injection** | A prompt template with one splice site, filled in by the framework | [Prompts]({{ '/morgana/pillars/prompts/' | relative_url }}) |
| **Intent** | A kind of request users can make. One agent answers each | [Your domain]({{ '/morgana/configuration/domain/' | relative_url }}) |
| **Issuer** | A named caller with its own key: a channel or a partner | [Deployment]({{ '/morgana/configuration/deployment/' | relative_url }}) |
| **MCP** | A protocol for serving tools to agents from outside | [Agents]({{ '/morgana/pillars/agents/' | relative_url }}) |
| **Morganize** | Alembic's last step: package the domain into the archive | [Alembic]({{ '/alembic/' | relative_url }}) |
| **Partner** | Another Morgana installation you trust to cooperate | [Agent to agent]({{ '/morgana/operations/a2a/' | relative_url }}) |
| **Personality** | The facet of Morgana an agent shows | [Prompts]({{ '/morgana/pillars/prompts/' | relative_url }}) |
| **Plugin** | A compiled domain dropped into `plugins/` | [Your domain]({{ '/morgana/configuration/domain/' | relative_url }}) |
| **Policy** | A global rule rendered into every agent's prompt | [Prompts]({{ '/morgana/pillars/prompts/' | relative_url }}) |
| **Quick reply** | A button Morgana or an agent offers for the next step | [Channels]({{ '/morgana/pillars/channels/' | relative_url }}) |
| **Rich card** | Structured content: sections and lists and badges | [Cauldron]({{ '/channels/cauldron/' | relative_url }}) |
| **Router** | The actor that sends a request to the agent for the winning intent | [Actors]({{ '/morgana/pillars/actors/' | relative_url }}) |
| **Rune** | The deliberately poor terminal channel | [Rune]({{ '/channels/rune/' | relative_url }}) |
| **Shared context** | Variables marked to travel between agents. First write wins | [Context]({{ '/morgana/pillars/context/' | relative_url }}) |
| **Territory** | The sentence other agents read to decide whether a question is this agent's | [Prompts]({{ '/morgana/pillars/prompts/' | relative_url }}) |
| **Tier** | One of three model slots: Economy and Efficiency and Performance | [Deployment]({{ '/morgana/configuration/deployment/' | relative_url }}) |
| **Tool** | A public method an agent can call to read or change something | [Agents]({{ '/morgana/pillars/agents/' | relative_url }}) |
| **Turn** | One user message and the answer to it | [At a glance]({{ '/morgana/' | relative_url }}) |
| **Widget** | Cauldron's chat as a launcher for any website | [Cauldron]({{ '/channels/cauldron/' | relative_url }}) |

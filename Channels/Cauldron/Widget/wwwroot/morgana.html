A perfectly ordinary page

This page knows nothing about Blazor, SignalR, .NET or Morgana. It sets its own fonts, its own colours and its own resets, and it would behave identically if it were rendered by a JSP, a PHP template, a Rails view or a static site generator.

The whole integration

<script src="https://your-cauldron-host/widget/morgana-widget.js" defer></script>

One tag, placed anywhere in the document. The widget reads the Cauldron origin off its own src, mounts a launcher in the bottom-right corner, and loads the chat only when a visitor actually opens it.

What to look for

The launcher below uses none of this page's typography or colours, and this page's stylesheet cannot restyle it — both directions are sealed by the shadow root. The conversation itself runs inside a sandboxed iframe served by Cauldron, so nothing on this page can read it and nothing in it can touch this page.
